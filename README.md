# OpenRouter Chat

Android-приложение: Jetpack Compose + Retrofit + OpenRouter API.

## Настройка

1. Скопируйте `local.properties.example` в `local.properties` (если файла нет).
2. Укажите `sdk.dir` и `OPENROUTER_API_KEY`.
3. Откройте папку `code` в Android Studio → Sync Gradle → Run.

## Сборка из терминала

После первого открытия в Android Studio (создастся полный Gradle Wrapper):

```bat
gradlew.bat assembleDebug
```
